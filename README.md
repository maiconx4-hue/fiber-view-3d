# Fiber View 3d

Crie uma aplicação gráfica e animada, usando as cores padrões da ABNT das fibras ópticas. A aplicação teria que ilustrar de forma tipo 3d ou 2d, oi mais próximo disso, a sequência de um projeto FTTH  começando do (Pop), switch, olt, portas pon, DGO, depois para CEO ( solitter 1:8) e CTO (splitter 1:8)

Isso precisa ser visível  em uma linha de tempo ( gráfica) para visualização, assim como tem que ser possível visualizar no mapa ( utilizar o que for melhor) mas que lembre o Google eart 3d... Esses dados precisa está traçado no mapa real.. tudo no mapa precisa ser editáveis, rotas , caixas,( mensuração) precisa passar uma idéia visual saindo do mapa e indo pra ilustração gráfica 3d, e vice-versa. 

Segue os equipamentos os detalhes, veja o exemplo de um como deve ser.

Ao clicar no ícone de triângulo no mapa ( CTO) abre a caixa gráfica que ilusta ela em 3d, com os dados ( MCP( nome da cidade). 05 (número do pop). 451( número da derivação). 01 ( número da CTO)
